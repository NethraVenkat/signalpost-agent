# Limitations

- Source planning and template synthesis are deterministic. The optional model interface is tested only with a fake provider; live adapters and pricing are not enabled. No UI, browser rendering, dated-activity extraction or search integration is implemented.
- Summary validation checks cited tokens and verbatim quotes rather than performing semantic fact verification. Fixed template phrases and exact approved model frames constrain wording. Registry activity/purpose and website self-descriptions are reported text, not independent assessments. Only the latest financial period is collected, so growth is unknown. Positive record counts summarize cited records, not exhaustive real-world counts; board records can represent multiple appointments of the same person.
- The saved 300-company synthesis gate restores accepted archived website claims and pages without rechecking their current ownership or accessibility. It proves deterministic evidence-linked summary construction, not fresh website or NAV coverage. Recent-registration summaries depend on the observation date; baseline and refresh notices intentionally differ.
- Website recall is constrained by four candidates, six requests, strict robots, timeouts and no external discovery. The latest measured publication rate is 20/300 (6.667%). Recall targets are development goals, not correctness gates. All 20 publications were reviewed with zero known wrong-company matches; this does not establish a universal error rate.
- NAV discovery checks known legal/brand/subunit names. Unknown trading names can be missed. Names without a distinctive four-letter token remain incomplete. Detail caps and source failures leave affected companies failed; a checked negative is name-scoped, not an exhaustive national identifier search.
- Bulk snapshots can be stale; live data can change between runs. Registered website fields do not alone prove ownership. Fixed-source idempotency does not promise zero changes on arbitrary future live data.
- Whole-NOK metadata is supported by four empirical exact-parent comparisons, while the API schema lacks normative scale documentation. Other/missing currencies remain unknown unless the source reports units. Only reported entity financial values are emitted.
- Concurrency, request, time and output defaults are configurable local choices. External evaluator schema/resource/handoff acceptance is not established. Whole-batch models and NAV update deduplication use memory proportional to selected envelopes/feed UUIDs; no external memory-limit compliance is claimed.
- Deadline cancellation and bounded processing preserve membership under source failures. Output cannot be guaranteed if storage or the process itself fails. Output ceilings prioritize minimal terminal membership and report when even that exceeds the configured limit.
- An unreadable input file has unknowable membership: output is empty with an explicit report warning. Exit zero means publication succeeded, not that research succeeded. Check source states, errors and independent verification.
- The DNS-pinning transport uses locked httpx/httpcore internals and needs regression verification on upgrades. UTF-8 decoding can lose non-UTF8 site text. Evidence records representative spans for compound claims; exact locators remain necessary.
- Website and advertisement content retain their own licences/terms. Historical carried-forward facts have original evidence and are not freshly verified. Inactive/expired ads must not be displayed as current.
- Ubuntu tests and the live registry smoke run execute through GitHub Actions. Their run links/results should be read for the published commit; previous Windows measurements alone are not Linux validation.
