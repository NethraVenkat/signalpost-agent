# Historical report archive

Subdirectories other than `evaluator-fixes/` preserve measurements, settings and verdicts at their named revision or capture date. Words such as “current” or “default” inside an archived report refer to that historical context. Historical budgets, test counts and dataset versions must not be relabelled as measurements of revised code.

Use [SUBMISSION](../SUBMISSION.md) for current commands and limits, [HISTORY_MAPPING](../HISTORY_MAPPING.md) for rewritten revision labels, and [evaluator fixes](evaluator-fixes/SUMMARY.md) for the revised entry's measured checks.

Some original envelopes and source bodies remain outside the clone. Such historical measurements are not independently reproduced by retaining a summary. The [bounded committed replay](evaluator-fixes/EVIDENCE.md) states its exact saved-output and source-byte scope. The [cleanup manifest](evaluator-fixes/PRUNED_DATA.json) records uncited generated JSON removed from the current tree; old helpers that require those historical generated files are not the current evaluator entry point.
