# F1 - scale-free financial arithmetic

Ratios require the same exact-company statement receipt and matching period, currency and unit-field value. A missing absolute unit cancels within that statement. YoY requires comparable consecutive annual periods, positive prior revenue, declared matching currency and matching unit fields; when both are absent, both receipts must use the same approved entity source schema. Absolute amounts never acquire an inferred scale; raw amounts are labelled accordingly. Independent verification repeats the statement/schema checks and arithmetic.
