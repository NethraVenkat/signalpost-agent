# W0 saved-evidence audit

Baseline code: d66a177a (revision/r5). No behavior, evidence, output, proof tier or publishing rule changes in this stage. The reproducible audit and artifacts are confined to reports/r5. No push, paid API, search or model calls.

The six saved samples contain 600 inputs and publish 29 websites. Registry-declared homepage baseline: 72 companies declare a homepage and 13 currently publish the declared domain (18.06%). This measures recall against registry declarations, not independently established current ownership. A published HIGH site remains HIGH; human verdicts do not change its proof tier. Per-sample denominators, source paths and input/report hashes are in rejections.json.

Overlapping rejection categories: 24 companies with recorded vetoes, 44 ambiguous website sections, 150 fetched-without-proof companies. Every included company's candidate outcomes, fetched HTML receipt hashes, titles and requested identity-location checks are in rejections.md/json. An old candidate-level rejection is not asserted to be the decision for every page from that candidate. Pages without a saved HTML body are explicitly unknown. Body-level name/contact occurrences are audit signals, never new website proof. Company publication excludes it from the rejection population even if an earlier candidate was rejected.

DNS: 2,511 saved candidate attempt records have no_such_domain (OS name-not-found, without retained authoritative RCODE); seven have generic dns_unavailable. The latter historically also covers nomination cutoffs. The seven unique non-name-not-found hosts were each queried once using Google Public DNS A-over-HTTPS with DNSSEC enabled and zero ECS. All seven returned SERVFAIL; none returned an A address. Exact JSON responses, query dates and hashes are in dns_recheck.json. No DNS audit result is published as identity evidence. An A-only check cannot exclude an AAAA-only host. These seven diagnostic HTTP calls are outside the saved evaluator runs and are reported separately, cost $0.

Public resolver documentation and current terms were checked before querying: [JSON API](https://developers.google.com/speed/public-dns/docs/doh/json), [terms](https://developers.google.com/speed/public-dns/terms), [privacy](https://developers.google.com/speed/public-dns/privacy). This uses the documented API rather than crawling HTML; dns.google/robots.txt was inaccessible through the browser source. No returned address was fetched and no challenge/access control was bypassed.

NAV: bundled index built 2026-11-13T08:23:53.796625Z contains 9,511 ads / 6,012 distinct employers. None of these workplace identifiers directly occurs in the 411,160-company universe. Saved exact-parent subunit proofs map three indexed employers to three universe companies. Those three companies have jobs in the 600 saved inputs: measured rate 5.00 companies per 1,000. The complete expected rate **cannot be calculated from the available snapshots**: there is no local nationwide underenheter snapshot and the index contains no parent IDs. The known-parent nationwide lower bound is 3 / 411,160 = 0.00730 per 1,000; it is not an expected-rate estimate. Index membership alone also does not establish a current ad.

The missing parent denominator remains an explicit audit limitation, not a fabricated zero or a successful check.
